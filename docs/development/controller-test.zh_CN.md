# 手柄支持与实时测试


## 小米遥控器与菜单更新（2026-10-14）

1.9 移植 FC 的遥控器输入与菜单修复。仅键盘类 HID 且 VID/PID 为 `2717:32B8` 时使用横握映射：实体右／上／左／下对应游戏上／左／下／右；TV=A、三横线菜单=B、主页=Start、返回=Select。长按返回 1 秒复用暂停／页面返回。完整名称 `MI RC` 和 `Xiaomi RC` 可作为待探测配对候选，实际输入支持仍依据 HID 描述符和设备身份。RC001/FW2671 描述符声明 6 字节而实际发送 8 字节键盘负载的问题使用限定兼容解码；普通键盘保留原映射。

所有外接设备共用固定完整手柄测试页，键盘／遥控器映射后的输入也会显示，未提供的控件保持零。主页第一项在未连接时显示“连接手柄”，连接后显示“游戏列表”。进入列表或从游戏返回时重建持键基线并清理机身旧事件，必须松开后重新确认才能启动；空列表断连也返回主页。

2026-10-14 已按批准向 COM14 的 `0x0` 写入 1.9 十四游戏完整包，写入哈希校验通过。45 秒启动／输入观察确认版本 1.9、匹配 ELF、小米 RC001/FW2671（`2717:32B8`）、报告兼容分支及《星之卡比》加载，未见 panic/abort/watchdog 或 HID 报告长度错误。用户确认配对、八键／释放、测试页显示、长按返回暂停，以及列表入页／游戏返回持键防误启动均正常；COM14 已释放。验收限于这些操作，重连、长期游玩和全部游戏兼容仍未验证。FC 的 RC001/FW2671 抓包和用户测试显示最多同时一个键；构造组合键回归不能证明实物支持多键。历史 1.8 镜像不含本次修改。随后已获单独批准并烧录实测；源码同步以 Git 记录为准，二进制产物仅本地保留。

## Select 暂停快捷键

游戏中长按 Select 约 1 秒打开暂停菜单，机身长按 OK 保留。短按 Select 及长按阈值前的输入仍交给游戏；进入、恢复游戏或重连时已按住 Select，须先松开再长按。键盘 I 共用 Select 映射，行为相同。测试页现支持机身长按 OK 或 Select 长按 1 秒返回。

## 连接和查看输入

已连接的手柄可以在主页使用方向键／左摇杆上下选择、A 确认，机身按键仍有效。进入主页时已按住的键和重连时的持键不会立即触发操作。测试页中手柄输入只用于显示，退出使用机身长按 OK 或 Select 长按 1 秒。

良值 L1241 按住配对键 + A 约三秒，选择 IINE GAMEPAD。27.02 是已有实测协议版本。八字节身份应答匹配 VID 0710 / PID 0220、但固件版本不同的设备，需要用户按机身 OK 明确确认；屏幕显示版本和“版本未验证”。长按 OK 取消，60 秒无确认则断开。确认不会跨重连、取消或重启保留；下次连接需返回配对页确认。其他型号、异常身份应答及损坏报文仍会被拒绝。

连接后进入“主页 → 手柄测试”，入口位于“游戏管理”下方，设置页不再保留此入口。页面显示双摇杆及坐标、方向键、A/B/X/Y、肩键、扳机、摇杆按键、Select/Start 和输入报告计数。标准 BLE HID 和 IINE 私有适配共用统一输入快照，保留模拟器死区处理和按键简化前的数据。按住时高亮，松开后下一帧直接恢复原色；不进行校准或改键。

测试期间短按手柄键仅用于显示。长按机身 OK 或 Select 1 秒返回，保留连接。断线立即清空输入并显示断开提示，键盘和遥控器共用完整测试布局。绘制前清除 GameBoy 的画面比较缓存，恢复游戏时不会沿用测试页像素。绘制复用现有 LCD 条带缓冲。

方向键绘制为箭头；Select / Start 位于底部。L3 / R3 不再单独显示，按下摇杆时对应圆形区域变色，松开立即恢复，不保留 600 毫秒标记。Home 和截图键不在页面显示。扳机条显示收到的数值；已测 L1241 上报数字端点，不能据此宣称支持模拟扳机。页面不测试震动、陀螺仪、Turbo 配置或全部硬件功能。

## 为什么使用这个配对模式？

[厂家指南](https://iine.store/pages/pocket-controller-ns-guide-manual)规定 Android 使用配对+A、iOS 使用配对+Y、PC 使用 USB；未说明 PC 无线模式的传输协议。

[贡献者协议记录](https://github.com/1ikeMcFlurry/esp32c3-iine-gamepad/blob/codex/main/docs/PROTOCOL.md)描述私有 IINE GAMEPAD BLE 配置接口；适配器使用带定时维持的临时输入测试通道。2026-10-12 用户向开发者确认：只实测 Android 模式，PC 无线模式待测，以本次确认收紧实测范围。两个固件已有按实际报告描述符解析的标准 Xbox BLE HID 路径；若 PC 模式提供兼容服务，可能直接使用。名称 Xbox Wireless Controller 本身不能证明 BLE HID、经典蓝牙或接收器兼容性，本次未声称 PC 无线已适配或通过实测。
