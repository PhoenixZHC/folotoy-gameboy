# GameBoy 1.9 发布表单

## 中文使用方法

1. 安装：用 USB 数据线连接 AI Passport，将完整固件从 `0x0` 写入。完整安装会覆盖固件、游戏、存档、设置和配对。十四游戏版含预装游戏，清洁版没有游戏。已有兼容 GB 安装可仅在 `0x10000` 更新应用，保留其他分区。
2. 连接输入：选择“连接手柄”，让输入设备进入配对模式，用机身上／下键选择，按 OK 连接。小米遥控器的配对操作以实物说明书为准。良值 L1241 按住配对键+A 约三秒，选择 IINE GAMEPAD；27.02 以外固件需要确认。仅支持适配的低功耗蓝牙设备，不支持经典蓝牙或 USB／2.4 GHz 接收器。
3. 开始游戏：连接后第一项变为“游戏列表”，选中游戏后按 A 或机身 OK。进入列表或退出游戏后，先松开确认键再重新按下。
4. 按键：手柄方向、A/B、Select/Start 保留原功能。键盘 W/A/S/D=上／左／下／右，J/K=A/B，I/L=Select/Start。小米遥控器横握：实体右／上／左／下=游戏上／左／下／右，TV=A、三横线菜单=B、主页=Start、返回=Select。确认、电源、语音和音量键未分配游戏动作。已测 RC001/FW2671 无法可靠同时保持多个键，不适合需要边移动边攻击的游戏操作。
5. 暂停和存档：长按机身 OK，或长按 Select／键盘 I／遥控器返回键约一秒，打开暂停菜单。原有长按返回的页面也支持此操作，跨页后须松开再长按。先在游戏内保存，再通过暂停菜单同步电池存档或正常退出；下次启动使用游戏自己的“继续”功能。保存的是卡带电池 RAM，不是任意时刻的即时存档。
6. 测试和设置：“手柄测试”供手柄、键盘和遥控器共用完整布局，缺失输入保持零。长按 OK 或 Select 返回。“设置”调整音量、亮度和声音，显示版本 1.9。
7. 管理游戏：进入“游戏管理”，连接无密码热点 FoloToy-GB，打开 `http://192.168.4.1`。提示无互联网时保持连接。可上传合法取得且兼容的 `.gb` 文件、改名和删除游戏；离开页面后热点关闭。删除游戏会删除关联存档，仍有相同 ROM 共用时除外。最多 16 款，受可用空间限制。
8. 排查：找不到设备时，确认配对模式，退出并重进连接页面扫描。无按键响应时检查“手柄测试”，能发现不等于兼容。管理页打不开时保持在“游戏管理”，确认连接 FoloToy-GB。无声音时检查声音开关和音量。不支持 GBA 或仅支持 GBC 的游戏。

## 中文更新日志

- 新增身份限定的小米遥控器横握映射，返回键对应 Select，长按复用暂停／返回。
- 修复 RC001/FW2671 描述符与实际报告长度不一致导致的按键无响应。
- 手柄、键盘和遥控器共用固定完整测试布局，显示按下和释放。
- 主页首项随连接状态切换；修复列表入页／游戏返回持键误启动及空列表断连返回。

获准的 1.9 十四游戏完整包已安装到 COM14，用户确认配对、八键／释放、测试页、长按返回暂停和菜单保护正常。重连、耐久和全部游戏／手柄兼容仍未验证。见[固件身份](gameboy-firmware.zh_CN.md)及[验证记录](../gameboy-validation.zh_CN.md)。表单归档不等于发布 GitHub Release。
