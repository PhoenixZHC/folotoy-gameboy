# GameBoy 1.8 发布表单

## 中文使用方法

1. 首次准备：将 GameBoy 1.8 十四游戏完整 BIN 从地址 0x0 烧录到 AI Passport（ESP32-C3、8 MB Flash）。完整安装会覆盖设备原有游戏、存档、设置和手柄配对信息。烧录完成后重启，预装游戏可离线游玩，无需连接路由器或互联网。
2. 连接输入设备：主页选择“配对键盘或手柄”，使用机身上／下键选设备，按 OK 连接。良值 L1241 按住“配对键 + A”约 3 秒，选择 IINE GAMEPAD；出现“版本未验证”时按机身 OK 尝试，长按 OK 取消。Xbox 1914 长按配对键至指示灯快速闪烁。仅支持兼容的蓝牙低功耗设备，不支持经典蓝牙或 USB／2.4 GHz 接收器。
3. 开始游戏：连接成功后进入游戏列表，机身或手柄上／下选择，按 OK 或手柄 A 启动。游戏中方向键／左摇杆控制方向，A/B 对应游戏 A/B，Start 开始、Select 选择；Xbox View/Menu 对应 Select/Start。键盘 W/A/S/D 为方向，J/K 为 A/B，L/I 为 Start/Select。
4. 暂停和返回：游戏中长按 Select 约 1 秒或长按机身 OK 打开暂停菜单，可继续、同步电池存档、设置、息屏或退出。设置、手柄测试、游戏管理及游戏列表支持相同长按返回；设置编辑时先结束编辑。在暂停页长按会保存后退出。每次操作后先松键，再次长按，避免连续跨页退出。未连接手柄时使用机身按键。
5. 手柄测试和设置：主页“手柄测试”可观察方向、双摇杆、按键和扳机上报状态；松开后高亮消失。主页“设置”可调整音量、亮度和声音开关，底部显示版本 1.8。
6. 增删游戏（可选）：进入“游戏管理”，手机或电脑连接无密码热点 FoloToy-GB，保留此连接，即使提示“无互联网”；浏览器打开 http://192.168.4.1，可上传有权使用的 .gb 文件、改名或删除游戏。最多 16 款，容量以页面显示为准。退出管理页后热点关闭。删除游戏会删除其对应存档；预装游戏删除后不会自动恢复。
7. 保存进度：先使用游戏内的存档功能，再在暂停菜单同步电池存档或正常退出。下次进入游戏后选择游戏内的“继续”。这是卡带电池存档，不是即时存档；不支持存档的游戏不能因此保存任意进度。息屏保留内存进度，但断电不会保留未保存进度。
8. 遇到问题：找不到手柄时，确认已进入兼容的 BLE 配对模式，长按机身 OK 取消后重试；网页打不开时确认仍停留在游戏管理页，且手机连接的是 FoloToy-GB。没有声音时检查设置中的声音开关和音量。不同 ROM 和手柄的兼容性、帧率会有差异；本固件面向 GB，不支持 GBA 或仅限 GBC 的游戏。

## 中文更新日志

1. 新增良值 IINE L1241 私有 BLE 协议支持，识别型号及固件版本；27.02 直接连接，其他同型号固件需本次确认，60 秒未确认自动断开。
2. 主页支持手柄方向选择和 A 确认，新增“手柄测试”入口，可实时查看双摇杆、方向键、按键及扳机状态，松开后立即恢复显示。
3. 新增长按 Select 约 1 秒暂停游戏及多页面返回，保留机身长按 OK；短按 Select 仍传给游戏，加入入局、恢复、重连和跨页面的松键保护。
4. 提供 1.8 十四游戏完整预装包，沿用原十四款游戏选集。已在 COM14 完整烧录，用户实测反馈无异常。

本次反馈不代表全部游戏通关、全部手柄／固件兼容或长期耐久测试通过。英文栏位见对应英文文档；镜像身份及验证范围见[固件交付记录](gameboy-firmware.zh_CN.md)。
